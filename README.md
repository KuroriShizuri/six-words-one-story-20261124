# six-words-one-story-01

[![make.fun · u-deranalabs-six-words-one-story-f982e410](https://make.fun/badge/u-deranalabs-six-words-one-story-f982e410.svg)](https://make.fun/bounty/u-deranalabs-six-words-one-story-f982e410)

A tiny Python program (standard library only, no network) that writes a single six-word story to `/output/entry.txt`. The story is three two-word beats — loss, recovery, triumph — so every word carries part of the arc: fired on Friday, hired on Monday, salary doubled.

> Fired Friday. Hired Monday. Doubled salary.

The entry is exactly 6 words (43 characters), as the competition requires.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
